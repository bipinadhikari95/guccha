# 🌸 Bloom & Petal — Artisan Flower Bouquets

A beautiful, modern website for a flower bouquet selling business featuring a **custom bouquet builder** as its unique selling point.

## ✨ Features

- **Custom Bouquet Builder** — Interactive 4-step builder where customers can:
  - Choose from 14+ flower varieties across 3 categories
  - Add extras like ribbons, chocolates, teddy bears, and vases
  - Select wrapping style and bouquet size
  - Review their creation with live pricing
- **Curated Bouquets** — Filterable gallery of pre-made arrangements
- **Responsive Design** — Beautiful on all devices
- **Smooth Animations** — Scroll-triggered animations and petal particles
- **Contact Form** — Ready for integration

## 🚀 Deployment

This site is hosted via **GitHub Pages**. Simply push to the `main` branch and enable GitHub Pages in your repository settings.

## 📸 Adding Your Photos

Replace the placeholder elements in `index.html`:
- **Bouquet photos**: Replace `.img-placeholder` divs in the bouquets grid with `<img>` tags
- **Individual flowers**: Replace `.flower-placeholder` divs in the builder with `<img>` tags
- **About section**: Replace placeholder divs with your shop photos

## 📂 Structure

```
├── index.html          # Main page
├── css/
│   └── style.css       # All styles
├── js/
│   └── main.js         # Interactivity & bouquet builder logic
└── images/             # Your photos go here
```

## 🎨 Customization

Edit CSS variables in `css/style.css` `:root` to change:
- Brand colors
- Fonts
- Border radius
- Shadows
